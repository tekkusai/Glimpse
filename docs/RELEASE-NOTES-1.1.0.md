# Glimpse 1.1.0

Glimpse 1.1.0 makes everyday previewing faster and more dependable. It also adds built-in updates: when a newer release is ready, Glimpse can let you know and install it without sending you back through Setup by hand.

PDF signing now works reliably across multi-page documents and stays with the PDF on screen. Arrow-key browsing is more consistent, Space works normally while renaming a file, and torrent previews no longer hold up the expand animation. Large STL and EPUB files also stop their work promptly when you move on.

Previews now refresh when a synced file changes without getting a new modified time. Markdown and Office previews keep outside links from loading on their own, and PDF page thumbnails run separately so a problem document cannot take down the resident app.

Setup keeps your Start with Windows choice across reinstalls. Full Word, Excel, and PowerPoint previews remain selected by default when LibreOffice is needed, and they are set up for the current user without a second administrator prompt.

If you are updating from 1.0.0, download **Glimpse-Setup-1.1.0.exe** below and run it normally. Your existing preferences are preserved.

**Requirements**

- Windows 10 1809 or newer
- WebView2 Runtime for web-backed previews; Setup installs it only when it is missing
- LibreOffice or OpenOffice for full Word, Excel, and PowerPoint previews; Setup can add LibreOffice when needed
