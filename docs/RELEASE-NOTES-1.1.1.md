# Glimpse 1.1.1

Pinned previews now give you a little more control. Pinning still keeps a preview open and above other windows by default, but you can turn off **Always on top** when you want it to behave like a normal window. It will stay available from the taskbar and Alt+Tab.

Glimpse now checks that a downloaded update is the expected installer and version before opening it.

Switching away from a fullscreen game should no longer cause a brief mouse stutter while Glimpse is running.

If you are updating from 1.1.0, download **Glimpse-Setup-1.1.1.exe** below and run it normally. Your existing preferences are preserved.

**Requirements**

- Windows 10 1809 or newer
- WebView2 Runtime for web-backed previews; Setup installs it only when it is missing
- LibreOffice or OpenOffice for full Word, Excel, and PowerPoint previews; Setup can add LibreOffice when needed

**SHA-256**

`68C40499EFCF441BA3BD4780AB3AE71B7B87733A119B6FDF06CF4414C96C8025`
