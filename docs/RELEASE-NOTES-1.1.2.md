# Glimpse 1.1.2

Glimpse no longer incorrectly shows an access notification when you open an installer or uninstaller.

Fixed a hang that could occur while scrolling or zooming through certain large PDFs.

For fresh installs, or if you're updating from version 1.0.0, download **Glimpse-Setup-1.1.2.exe** below and run it. Any existing preferences are preserved.

**Requirements**

- Windows 10 1809 or newer
- WebView2 Runtime for web-backed previews; Setup installs it only when it is missing
- LibreOffice or OpenOffice for full Word, Excel and PowerPoint previews; Setup can add LibreOffice when needed

**SHA-256**

`C4E726BCE4C6B4FD7B793DC29937FD72241C16193535B646162CD292F303A292`

The installer is not code-signed yet, so Windows may show a SmartScreen warning.
